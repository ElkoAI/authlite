Build a lightweight, dependency-free PHP authentication library—call it AuthLite. Runs on pure PHP seven point four or up, needs only SQLite as storage—creates auth dot db on first use, handles tables: users, tokens, sessions. Signup: email plus password, sends confirm link via mail slash—expires day old. One function, AuthLite::init(), call it early—fires session start, sets secure flags, checks login state, gives back user array or false. Want stateless? Toggle JWT in config—signs with app secret, base six-four, sha two-five-six. Social side: Google, Facebook, Apple—raw curl to their endpoints, store client I-D, secret in config dot php. No SDK, no OAuth libs. Let folks log in via social and skip email step. Debug mode—secret path, slash auth slash vault, hit it with master key from config. If right, drops you to plain form: add username, password—hashes and inserts to SQLite live. Then, regular login checks that table too, no questions asked.
